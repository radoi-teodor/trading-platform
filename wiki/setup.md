# Setup Guide

Complete installation guide for Ubuntu 22.04 and 24.04.

## Prerequisites

| Software | Version | Purpose |
|----------|---------|---------|
| PHP | 8.3+ | Laravel backend |
| Composer | 2.x | PHP dependency manager |
| Python | 3.11+ | Agent scripts |
| Redis | 7.x | Pub/sub + caching |
| MySQL | 8.x | Database (optional, SQLite is default) |
| Claude CLI | latest | AI analysis binary (pre-installed) |
| Node.js | **not needed** | Tailwind CSS is loaded via CDN |

## Step 1: System Packages

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl wget unzip software-properties-common \
    build-essential libssl-dev libffi-dev
```

## Step 2: PHP 8.3

```bash
# Add Ondrej's PPA
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update

# Install PHP 8.3 with required extensions
sudo apt install -y php8.3 php8.3-cli php8.3-fpm php8.3-mysql php8.3-sqlite3 \
    php8.3-mbstring php8.3-xml php8.3-curl php8.3-zip php8.3-bcmath \
    php8.3-redis php8.3-intl php8.3-gd

# Verify
php -v
# Should show: PHP 8.3.x
```

## Step 3: Composer

```bash
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

# Verify
composer --version
```

## Step 4: Python 3.11+

```bash
# Ubuntu 24.04 ships with Python 3.12, which works fine.
# On Ubuntu 22.04 you may need the deadsnakes PPA:
sudo add-apt-repository ppa:deadsnakes/ppa -y
sudo apt update
sudo apt install -y python3.11 python3.11-venv python3.11-dev python3-pip

# Verify
python3 --version
# Should show: Python 3.11.x or higher
```

## Step 5: Redis

```bash
sudo apt install -y redis-server

# Enable and start
sudo systemctl enable redis-server
sudo systemctl start redis-server

# Verify
redis-cli ping
# Should respond: PONG
```

## Step 6: MySQL (Optional)

SQLite is the default database and requires no setup. If you prefer MySQL:

```bash
sudo apt install -y mysql-server

# Secure the installation
sudo mysql_secure_installation

# Create database and user
sudo mysql -e "CREATE DATABASE trading_platform CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
sudo mysql -e "CREATE USER 'trading'@'localhost' IDENTIFIED BY 'your_secure_password';"
sudo mysql -e "GRANT ALL PRIVILEGES ON trading_platform.* TO 'trading'@'localhost';"
sudo mysql -e "FLUSH PRIVILEGES;"
```

If using SQLite (default), the database file is created automatically at `laravel/database/database.sqlite`.

## Step 7: Claude CLI Verification

The Claude Code CLI binary should already be installed on the system. Verify it works:

```bash
# Check binary exists
which claude
# or
claude --version

# Test a simple prompt
claude -p "Say hello" --output-format json
```

If the binary is not found, ensure it is in your `PATH` or set the `CLAUDE_BINARY_PATH` variable in `.env` to the full path.

## Step 8: Clone and Configure

```bash
cd /opt  # or your preferred directory
git clone <repository-url> trading-platform
cd trading-platform
```

### Environment File

```bash
cp laravel/.env.example .env
# or create .env at project root:
nano .env
```

Essential `.env` settings:

```ini
# Application
APP_NAME="AI Trading Platform"
APP_ENV=local
APP_KEY=   # Generated by artisan key:generate
APP_DEBUG=true
APP_URL=http://localhost:8000

# Database (SQLite - default)
DB_CONNECTION=sqlite

# Database (MySQL - optional)
# DB_CONNECTION=mysql
# DB_HOST=127.0.0.1
# DB_PORT=3306
# DB_DATABASE=trading_platform
# DB_USERNAME=trading
# DB_PASSWORD=your_secure_password

# Redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=

# Queue
QUEUE_CONNECTION=database

# Claude CLI
CLAUDE_BINARY_PATH=claude

# Broker (paper trading by default)
BROKER_TYPE=paper

# Market data (yfinance is free and requires no key)
# ALPHAVANTAGE_API_KEY=
# FINNHUB_API_KEY=
# TWELVEDATA_API_KEY=

# Notifications (all optional)
# MAIL_MAILER=smtp
# MAIL_HOST=smtp.gmail.com
# MAIL_PORT=587
# MAIL_USERNAME=
# MAIL_PASSWORD=
# MAIL_FROM_ADDRESS=

# TELEGRAM_BOT_TOKEN=
# TELEGRAM_CHAT_ID=

# DISCORD_WEBHOOK_URL=

# Logging
LOG_LEVEL=INFO
```

## Step 9: Laravel Setup

```bash
cd laravel

# Install PHP dependencies
composer install --no-dev --optimize-autoloader

# Generate application key
php artisan key:generate

# Create SQLite database file (if using SQLite)
touch database/database.sqlite

# Run migrations
php artisan migrate --force

# Seed demo data
php artisan db:seed --force

# Verify
php artisan tinker --execute="echo App\Models\User::count() . ' users';"
```

## Step 10: Python Setup

```bash
cd agents

# Create virtual environment
python3 -m venv venv

# Activate
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Verify
python -c "from agents.config import Config; print('Config OK')"
```

## Step 11: Start the Platform

### Using the startup script (recommended)

```bash
cd /opt/trading-platform
chmod +x start.sh
./start.sh
```

This starts:
- Laravel queue worker (background)
- Laravel dev server on port 8000
- Python agents (background)

### Manual startup (for development)

Terminal 1 - Laravel:
```bash
cd laravel
php artisan serve --host=0.0.0.0 --port=8000
```

Terminal 2 - Queue worker:
```bash
cd laravel
php artisan queue:work --tries=3 --timeout=120
```

Terminal 3 - Python agents:
```bash
cd agents
source venv/bin/activate
python main.py
```

### Access the application

Open http://localhost:8000 in your browser.

Default login credentials:
- **Email:** `demo@example.com`
- **Password:** `password`

## Docker (Alternative)

A `docker-compose.yml` is provided at the project root:

```bash
docker-compose up -d
```

This spins up all services (Laravel, Python agents, Redis, and optionally MySQL) in containers.


## Troubleshooting

### PHP extension missing

```
Error: PHP extension "redis" is not installed.
```

Install the missing extension:
```bash
sudo apt install php8.3-redis
```

Common extensions that may be missing: `redis`, `sqlite3`, `mbstring`, `xml`, `bcmath`, `gd`.

### Composer memory limit

```
PHP Fatal error: Allowed memory size of ... bytes exhausted
```

Run Composer with unlimited memory:
```bash
COMPOSER_MEMORY_LIMIT=-1 composer install
```

### SQLite database not found

```
Database file at path [database/database.sqlite] does not exist.
```

Create the file:
```bash
touch laravel/database/database.sqlite
```

### Redis connection refused

```
Connection refused [tcp://127.0.0.1:6379]
```

Check Redis is running:
```bash
sudo systemctl status redis-server
sudo systemctl start redis-server
```

### Python venv activation fails

```
bash: venv/bin/activate: No such file or directory
```

Create the virtual environment first:
```bash
python3 -m venv venv
source venv/bin/activate
```

### Claude CLI not found

```
FileNotFoundError: [Errno 2] No such file or directory: 'claude'
```

Either add the Claude binary to your `PATH` or set the full path in `.env`:
```ini
CLAUDE_BINARY_PATH=/usr/local/bin/claude
```

### Port 8000 already in use

```
Failed to listen on 0.0.0.0:8000
```

Kill the existing process or use a different port:
```bash
# Find what is using port 8000
sudo lsof -i :8000

# Use a different port
php artisan serve --port=8080
```

### MySQL access denied

```
SQLSTATE[HY000] [1045] Access denied for user 'trading'@'localhost'
```

Verify credentials match between MySQL and `.env`:
```bash
sudo mysql -u trading -p -e "SHOW DATABASES;"
```

### Python import errors

```
ModuleNotFoundError: No module named 'redis'
```

Ensure the venv is activated and dependencies are installed:
```bash
source agents/venv/bin/activate
pip install -r agents/requirements.txt
```
