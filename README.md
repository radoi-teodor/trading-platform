# Trading X

An automated crypto trading platform for one operator. LLM agents research markets and write strategies;
deterministic code tests, sizes, limits and executes them. One Laravel application, Binance first, spot and USD-M
perpetuals.

Status: Phase 0 (foundations) of the rebuild. Nothing trades yet.
